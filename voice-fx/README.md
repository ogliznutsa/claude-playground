# 🎙️ Voice FX

Веб-приложение для записи голоса с микрофона и наложения эффектов
(робот, бобёр, монстр, эхо, рация). Чистый HTML/CSS/JS на Web Audio API —
**без зависимостей и без сборки**.

## Возможности

- 🔴 Запись голоса с микрофона (с таймером и осциллограммой)
- 🎛️ Эффекты в реальном времени:
  - 🤖 **Робот** — кольцевая модуляция + дисторшн
  - 🦫 **Бобёр** — высокий ускоренный голос
  - 👹 **Монстр** — низкий замедленный голос
  - 🌀 **Эхо** — задержка с обратной связью
  - 📻 **Рация** — узкая полоса + дисторшн + компрессия + фоновая статика
  - 😣 **Тужится** — «грудной» резонанс + рык + медленная дрожь от натуги
- ▶️ Бегущая полоска по осциллограмме во время воспроизведения
- ▶️ Мгновенная предпрослушка (по клику на эффект)
- ⬇️ Экспорт результата в `.wav`

## Запуск

Микрофону нужен «безопасный контекст», поэтому открывать файл напрямую
(`file://`) нельзя — нужен локальный сервер (подойдёт `localhost`).

```bash
cd /Users/oleg/dev/voice
python3 -m http.server 8000
```

Затем открой в браузере: **http://localhost:8000**

При первой записи браузер спросит разрешение на доступ к микрофону —
нужно разрешить.

> Альтернатива без Python:
> `npx serve .` или любой другой статический сервер.

## Как пользоваться

1. Нажми большую круглую кнопку — начнётся запись.
2. Скажи что-нибудь и нажми кнопку ещё раз, чтобы остановить.
3. Выбери эффект — он сразу проиграется.
4. Нажми **Скачать (.wav)**, чтобы сохранить результат.

## Как добавить свой эффект

В `app.js` в объект `EFFECTS` добавь запись и функцию-цепочку Web Audio:

```js
myfx: {
  label: 'Мой эффект', emoji: '✨', playbackRate: 1, tail: 0,
  build: (ctx, input) => {
    const node = ctx.createBiquadFilter();
    // ... настрой узлы ...
    input.connect(node);
    return node; // вернуть выходной узел
  },
},
```
